# Photo prompt patterns (six-panel grids)
Generate in one tool with identical settings for a cohesive set. Ask for a 3x2 gutter grid, 3:2 panels (landscape sets) or 4:5 (people sets), "no text, no logos, no watermarks".
- **Landscape/minimal**: one focal point per panel, tiny tourists for scale, palette terracotta / bone / sand / charcoal + one orange accent, soft golden light, subtle sun flare, film grain.
- **People/stock style**: candid, seen from behind or in profile, earth-toned clothing with one mustard/rust/orange accent, negative space above for a headline, diverse ages.
- **Ad layout test**: photo top 75%, rounded terracotta banner with bold white headline, small white wordmark top-left, mustard footprint trail. AI often misspells text, so add real type in code for finals.
