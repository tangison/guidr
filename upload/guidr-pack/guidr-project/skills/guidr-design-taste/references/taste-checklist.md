# Taste checklist (score each item: pass / fix)

## Focus and hierarchy
- [ ] One clear focal point; the eye knows where to start
- [ ] Headline, support line and action are visually distinct
- [ ] No more than three type sizes inside a component
- [ ] Primary action is obvious and singular

## Colour
- [ ] Only one accent is loud
- [ ] Text and UI meet contrast (4.5:1 body, 3:1 large and UI)
- [ ] Terracotta not used for small text on white
- [ ] Mustard used only as fill or on dark

## Space and layout
- [ ] Spacing values come from the scale
- [ ] Sections breathe; nothing is crammed
- [ ] Grid and alignment are consistent; edges line up
- [ ] Mobile layout designed first and works at 320 px

## Imagery
- [ ] Photos are on brand (warm, honest, travellers from behind)
- [ ] Crops respect faces and horizons; ratios from the standard list
- [ ] Rounded to the container radius
- [ ] Scrim present where text sits on an image
- [ ] Alt text written

## Components and details
- [ ] No default or unstyled controls
- [ ] Icons one family, one stroke weight
- [ ] At most two shadows visible; hairlines used for separation
- [ ] Hover, focus, pressed, disabled, loading, empty, error states exist
- [ ] Footprint motif used meaningfully

## Copy
- [ ] Plain, specific, warm; no hype; no exclamation marks
- [ ] Buttons are verbs; prices formatted "From N$ 600 per person"
- [ ] Errors say what happened and what to do next

## Motion
- [ ] Motion explains something
- [ ] Transform and opacity only; durations from the scale
- [ ] Reduced-motion version exists

## Final test
- [ ] If you removed one element, would it improve? (If yes, remove it.)
- [ ] Would this sit comfortably in a well-edited travel magazine?
